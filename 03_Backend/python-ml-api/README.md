# Aqualytica - Python Machine Learning API Gateway

This directory houses the machine learning prediction microservice for **Aqualytica – AI-Powered Water Quality Intelligence Platform**. The service uses a Flask REST API to serve predictions generated by a trained Random Forest Classifier.

---

## Technical Stack
- **Web Framework**: Python Flask (handling asynchronous classification requests)
- **Scientific Toolkit**: Pandas, NumPy, Scikit-learn (StandardScaler, RandomForestClassifier)
- **Model Storage**: Serialization via `pickle` files (`random_forest_model.pkl`, `scaler.pkl`)
- **API Communication**: JSON payloads, CORS enabled for cross-origin frontend queries

---

## Directory Architecture
```
03_Backend/python-ml-api/
├── app.py                      # Flask REST server entry point
├── random_forest_model.pkl      # Serialized Random Forest Classifier
├── scaler.pkl                  # Serialized Scikit-learn feature scaler
└── requirements.txt            # Python environment dependencies
```

---

## Machine Learning Pipeline
1. **Feature Input**: Accepts 9 parameter inputs: pH, Temperature, Turbidity, TDS, Conductivity, Nitrate, Chloride, etc.
2. **Feature Scaling**: Applies standard normal distribution scaling matching training distribution metrics.
3. **Random Forest Classification**: Passes inputs through an ensemble of randomized decision trees.
4. **Probability Score**: Evaluates positive prediction confidence range (0% to 100%).

---

## API Endpoints

### 1. Health Status Ping
- **Endpoint**: `GET /`
- **Output**:
  ```json
  "Random Forest Model & Scaler Online"
  ```

### 2. Predict Water Quality Potability
- **Endpoint**: `POST /predict`
- **Headers**: `Content-Type: application/json`
- **Request Payload**:
  ```json
  {
    "ph": 7.2,
    "temperature": 22.5,
    "turbidity": 0.8,
    "totalDissolvedSolids": 180.0,
    "conductivity": 350.0,
    "nitrate": 2.5,
    "chloride": 85.0
  }
  ```
- **Response Payload**:
  ```json
  {
    "prediction": "Potable",
    "confidence": 79.29
  }
  ```

## Getting Started

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Launch Development API Server
```bash
python app.py
```
The Flask microservice will start listening on port `5000` (`http://localhost:5000`).
