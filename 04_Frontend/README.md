# Aqualytica - Frontend Workspace Gateway

This directory houses the user portals and dashboard clients for **Aqualytica – AI-Powered Water Quality Intelligence Platform**.

---

## Front-End Core Details

### 1. Client Dashboard Portal (`/water-quality-frontend`)
- **Technology Stack**: React, Vite, Tailwind CSS, Framer Motion, and Recharts.
- **Port**: `5173`
- **Key Modules**:
  - Liquid canvas waves, bubble particles, cursor trail graphics.
  - Interactive parameters guidelines.
  - Interactive telemetry simulations.
  - Diagnostic logs notification system.
  - Custom line and area chart themes.
  - High-fidelity landscape printable PDF certificate utility.
