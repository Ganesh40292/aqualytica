# Aqualytica - Project Documentation

This directory contains reports, presentations, flow diagrams, and design documents for **Aqualytica – AI-Powered Water Quality Intelligence Platform**.

---

## Documentation Items

1. **Project Synopsis & Proposal**:
   - Project definitions, objectives, literature survey, methodologies, and timeline charts.

2. **System Design & Architecture**:
   - Block diagrams detailing the ESP32 sensor integration, Spring Boot service middleware layer, Flask model predictor API, and React frontend portals.
   - UML diagrams (use-case, class, sequence flows, activity tracking).

3. **User Manual**:
   - Setup guidelines, server starting commands, calibration references, and troubleshooting procedures.
